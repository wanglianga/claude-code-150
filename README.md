# 工地临时材料领用退库损耗与班组核算平台

面向项目部的材料全链路管理：**采购入库质检 → 预算 → 班组领料申请 → 仓管核对发料（施工进度/预算量/已领量/现场库存）→ 班组长确认进入现场消耗 → 退库 → 损耗 → 变更签证 → 盘点 → 月底班组材料成本核算**，并为项目经理、财务、预算员、材料员分别提供偏差、结算、采购反推、损耗复盘视图。

技术栈：**React 18 + Vite + Ant Design 5 + Recharts** / **Spring Boot 3.2 + Spring Data JPA** / **MySQL 8**（H2 内存库用于本地免依赖开发与测试）。

## 一、一键启动（Docker Compose）

要求安装 Docker 20+ 与 Docker Compose v2。

```bash
cd /workspace/150-a
docker compose up -d --build
```

启动后：

| 服务 | 地址 | 说明 |
|---|---|---|
| 前端 | http://localhost:8088 | Nginx 托管 SPA 并反代 /api |
| 后端 API | http://localhost:8080/api | REST API |
| MySQL | localhost:3306 | 库 `material`，用户 `material/material123`，root `root123` |

首次启动会自动建表并写入演示数据（约 10~30 秒，后端健康依赖 MySQL 就绪）。
重置数据：`docker compose down -v && docker compose up -d --build`。

## 三、本地开发（免 Docker / 免 MySQL）

### 后端（H2 内存库，含演示数据）

```bash
cd backend
mvn spring-boot:run -Dspring-boot.run.profiles=h2
# 或： mvn package && java -jar target/material-platform-1.0.0.jar --spring.profiles.active=h2
```
后端运行在 http://localhost:8080 。

连接本地 MySQL（可选）：准备库 `material` 后直接运行
`mvn spring-boot:run`（默认连 `localhost:3306/material`，可用环境变量
`DB_HOST/DB_PORT/DB_NAME/DB_USER/DB_PASSWORD` 覆盖；`SEED_ENABLED=false` 可关闭种子数据）。

### 前端

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173 ，/api 已代理到 8080
```
生产构建：`npm run build`（产物在 `frontend/dist`）。

## 四、验证方式与演示数据

### 自动化验证

```bash
cd backend && mvn test
```
集成测试（H2）覆盖：登录鉴权 → 超预算发料被拦截 → 勾选超预算放行后发料扣库存 →
班组长确认 → 质检不合格批次被冻结 → 月度核算包含退库冲减与供应商索赔口径。

### 建议手工验证路径（用仓库账号 warehouse / 班组长账号 wangqiang）

1. **入库与质检**：「入库与库存」可看到 7 大类材料批次（钢筋辅材/防水卷材/瓷砖/线管/砂浆/五金/安全防护用品），
   其中 `RK-20261001-001` 瓷砖为**供应商补货延迟刚到货待检**、`RK-20260925-001` 安全网**质检不合格被冻结**；可自行登记入库并做质检放行/冻结。
2. **领料三阶段**：「领料单」
   - 单号 `LL-20261003-001`（2#楼钢筋，预算 10t 申请 12t）：点「发料核对」可见预算/已领/剩余/库存，
     不勾选“超预算放行”直接发料**会被拦截**；勾选后可强制发料，发料后用 `wangqiang` 登录点「班组长确认」。
   - 单号 `LL-20261003-002`（**夜间紧急**领料）：红色“夜间紧急”标记，可紧急发料，次日班组长补确认。
3. **退库**：「退库单」
   - 已含：临时追加扎丝未用（可复用，冲减班组成本）、瓷砖规格领错开箱报废（班组责任成本，不回库存）；
     施工变更防水余料退库为草稿，用仓管账号「确认退库」，可复用余料回补批次库存。
4. **损耗**：「损耗登记」已含瓷砖破损（施工错误/班组扣款）、砂浆过期（保管不当/仓内调减库存）、
   线管壁厚不达标（供应商质量/索赔并调减库存）、设计变更旧排版备料（项目承担）、钢筋下料合理损耗。
   财务/仓管可「修正归属」，现场损耗与仓内损耗通过“是否调减仓库库存”区分。
5. **变更签证**：「变更签证」可见已批准的卫生间设计变更（索赔 2700 元）和一条待审批的施工变更，可批准/驳回。
6. **盘点账实不符**：「库存盘点」→ 发起盘点（自动快照全部批次账面数量）→ 修改实盘数量、指定盘亏责任
   （班组/供应商/项目）→ 确认后自动调账，盘亏生成损耗记录，供应商责任自动计入质量索赔。
7. **月底核算**：「月度班组核算」选择当月 → 「生成/重算核算」。
   口径：**班组材料成本 = 实领成本 − 可复用退库 + 班组责任损耗**；供应商质量损耗进索赔不扣班组；设计变更与合理损耗项目承担。
8. **项目经理**：「材料偏差分析」按楼栋/工序/班组对比预算与真实材料成本，柱状图红超绿省，按偏差率排序。
9. **财务**：「财务结算」查看供应商入库额−质量索赔=应付、班组材料成本+责任损耗扣款、已批准变更索赔。
10. **预算员**：「采购反推/分包」
    - 采购反推算法：实际单耗系数 = 本期净耗 ÷ (预算总量 × 形象进度%)；反推完工总需 = 预算总量 × 系数；
      建议采购 = max(反推完工尚需 − 合格在账库存, 0)。待检/不合格批次不计入可用库存。
      演示数据中瓷砖、防水卷材会出现真实补货缺口。
    - 「预算与进度」页可维护各楼栋/工序/材料预算量与形象进度%。
11. **材料员复盘**：「损耗复盘」按设计变更/施工错误/保管不当/供应商质量/合理损耗五类出饼图、柱图、责任去向与明细。

> 说明：演示单据日期取“当前日期前几天”，因此选择登录当月即可在各看板看到数据。

## 五、工程结构

```
150-a/
├── docker-compose.yml          # 一键启动 mysql + backend + frontend
├── backend/                    # Spring Boot 3.2 / JPA / MySQL
│   ├── Dockerfile  settings.xml
│   └── src/main/java/com/site/material/
│       ├── domain/             # 13 张核心表实体
│       ├── repo/               # Spring Data 仓库
│       ├── service/            # 库存/领料/退库/损耗/盘点/核算/分析业务
│       ├── web/                # REST 控制器
│       ├── security/           # Token 鉴权过滤器（演示用）
│       └── bootstrap/          # 演示种子数据
└── frontend/                   # React + Vite + AntD + Recharts
    ├── Dockerfile  nginx.conf
    └── src/pages/              # 13 个业务页面
```

### 核心数据链路

```
入库批次(质检冻结) ──发料核对(预算/已领/库存/进度)──> 领料单(APPLIED→ISSUED→CONFIRMED)
                                                          │
        退库单(REUSE冲减/SCRAP班组责任) <────────────────┤
        损耗(设计变更/施工错误/保管不当/供应商质量/合理损耗) │
        变更签证(批准后索赔)                               │
        盘点(账实不符→自动调账+盘亏损耗)                    │
                                                          ▼
                            月度核算(楼栋+工序+班组+材料)
                     ┌──────────────┬───────────────┬─────────────┐
                     ▼              ▼               ▼             ▼
              项目经理偏差      财务结算      预算员采购反推   材料员损耗复盘
```

## 六、备注

- 鉴权为演示级内存 Token（登录返回 `X-Auth-Token`），生产环境请替换为 JWT/Spring Security。
- 金额一律 `BigDecimal(16,2)`，发料按批次锁定实际单价；预算成本用入库加权均价。
- JPA `ddl-auto=update` 适合演示；正式环境建议改用 Flyway/Liquibase 迁移脚本。
